# ☕ FPT University - PRJ301: Java Web Applications

Kho tài liệu học tập, thực hành Lab và luyện thi **Practical Exam (PE)** môn PRJ301, tích hợp gia sư ảo **DeepTutor**.

---

## 📚 Cấu Trúc Thư Mục Môn Học

| Phân khu | Nội dung chi tiết |
| :--- | :--- |
| `01_Lectures_Theory/` | Vòng đời Servlet (`init`, `service`, `destroy`), JSP, Expression Language (EL), thẻ JSTL Core (`<c:forEach>`, `<c:if>`), Session & Cookie, Filter. |
| `02_Database_JDBC/` | Kết nối SQL Server với JDBC Driver, mẫu `DBContext`, các hàm DAO (CRUD: Create, Read, Update, Delete) chuẩn bảo mật chống SQL Injection. |
| `03_MVC_Architecture/` | Thiết kế hệ thống theo MVC Model 2, tách lớp Controller (Servlet), Service, DAO, DTO/Entity. |
| `04_Labs_Workshops/` | Toàn bộ 6 bài thực hành Lab theo đề cương của Đại học FPT. |
| `05_Practical_Exam_PE/` | Ngân hàng đề thi PE các kỳ (Summer, Fall, Spring) có phân tích bẫy và checklist chấm điểm. |
| `06_Assignment_Project/` | Đồ án lớn môn học (Website thương mại điện tử, đặt phòng, quản lý sinh viên...) có giỏ hàng và phân quyền Admin/User. |
| `Roadmaps/` | Lộ trình ôn thi cấp tốc PE trong 2 tuần / 1 tháng do DeepTutor xây dựng. |
| `Quizzes/` | Bộ câu hỏi trắc nghiệm ôn thi Final Exam (FE). |
| `Notes/` | Bảng cheatsheet cú pháp JSTL, JDBC và các lỗi Servlet thường gặp. |
